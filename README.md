# 홍길동부동산 · 경산 아파트 브리핑

공개 사이트에서는 GitHub Pages의 제약에 따라 예시 데이터로 화면과 지도를 확인할 수 있습니다. 실제 국토교통부·한국부동산원 자료는 아래 로컬 서버 실행 방식으로 조회합니다. API 키는 GitHub 저장소나 공개 페이지에 저장하지 않습니다.

Windows에서 프로젝트 폴더의 **대시보드 실행.cmd**를 더블클릭하면 서버가 시작되고 기본 브라우저가 열립니다. 브리핑 중에는 실행 창을 열어 두세요. Node.js 22 이상이 필요하며 별도 패키지 설치는 필요 없습니다.

터미널에서도 실행할 수 있습니다.

```powershell
npm start
```

브라우저에서 [대시보드](http://127.0.0.1:3000/)를 엽니다. 우측 상단 톱니바퀴에서 두 API 키를 연결할 수 있습니다. 화면에서 입력한 키는 로컬 서버 메모리에만 저장됩니다. 재시작 후에도 연결을 유지하려면 `.env.example`을 `.env`로 복사하고 값을 입력한 다음 서버를 다시 시작하세요. 공공데이터포털에서 아파트 매매 및 전월세 실거래 API 각각의 활용 승인이 필요합니다.

- 주간은 종료일을 포함한 7일, 월간은 종료일이 속한 달의 1일부터 종료일까지입니다. 최대 93일을 직접 선택할 수 있습니다.
- Top 10은 조회 기간의 공개 신고 건수 순입니다. 동률은 최근 계약일과 단지명 순으로 정렬합니다. 확인 가능한 매매 해제 건은 제외합니다. 선택한 단지의 최근 계약은 종료일 기준 약 120일 범위에서 최대 4건을 표시합니다.
- 입지 정보는 지도에 등록된 반경 2.8 km 내 시설과 직선거리를 표시합니다. 학교 배정, KTX 정차 및 개발계획의 최신 상태는 화면의 공식 안내에서 확인할 수 있습니다. OSM에 단지명이 없을 경우 지도 검색을 이용하거나 선택적으로 VWorld 키를 설정할 수 있습니다.
- 추천매물 샘플은 표시 방법을 보여주기 위한 예시입니다. 추가한 매물은 현재 브라우저에 저장됩니다.
- 미분양은 화면 하단의 국토교통 통계누리에서 확인할 수 있습니다.
